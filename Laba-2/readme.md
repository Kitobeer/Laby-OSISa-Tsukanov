## Задача 3

### Подробно про все команды (ИИ был в помощь)

* **`groupadd developers`** (`group add` — добавить группу)
  * Создаёт новую группу пользователей в системе и записывает её в файл `/etc/group` (выделяя ей уникальный числовой идентификатор — GID). Группы нужны, чтобы не выдавать права каждому человеку по отдельности, а настроить их один раз на всю команду.

* **`useradd -m -s /bin/bash -G developers,testers admin`** (`user add` — добавить пользователя)
  * Создаёт новую учётную запись в системе (записывает данные в `/etc/passwd`, `/etc/shadow` и `/etc/group`).
  * **Флаг `-m` (`--create-home`):** принудительно создаёт домашний каталог пользователя (`/home/admin`) и копирует туда базовые настройки из `/etc/skel`. Без этого флага в Debian домашняя папка не создаётся.
  * **Флаг `-s /bin/bash` (`--shell`):** назначает пользователю полноценную командную оболочку Bash вместо урезанной `/bin/sh` (чтобы работали стрелки истории, автодополнение по `Tab` и нормальное приглашение).
  * **Флаг `-G` (`--groups`):** сразу при создании добавляет пользователя в указанные дополнительные группы (строго через запятую без пробелов).

* **`usermod -aG developers user1`** / **`usermod -L user2`** (`user modify` — изменить пользователя)
  * Изменяет параметры уже существующей учётной записи.
  * **Флаги `-aG` (`--append` + `--groups`):** добавляет пользователя в дополнительную группу. **Критически важный нюанс:** если написать просто `-G` без `-a`, система *перезапишет* список групп и удалит пользователя из всех предыдущих, где он уже состоял.
  * **Флаг `-L` (`--lock`):** блокирует учётную запись (ставит символ `!` перед хэшем пароля в `/etc/shadow`, делая вход по паролю невозможным). Для разблокировки используется `-U`.

* **`passwd user1`** / **`passwd -S user2`** (`password` — пароль)
  * Управляет паролем пользователя (записывает его зашифрованный хэш в `/etc/shadow`).
  * **Без флагов (`passwd user1`):** задаёт или меняет пароль для указанного пользователя. Без этой команды новый юзер после `useradd` остаётся без пароля и не может войти в систему.
  * **Флаг `-S` (`--status`):** выводит краткий статус пароля (`L` — заблокирован, `P` — активный пароль установлен, `NP` — пароль не задан).

* **`chown admin:developers /home/admin/logs`** (`change owner` — сменить владельца)
  * Меняет пользователя-владельца и/или группу-владельца файла или каталога.
  * **Синтаксис `пользователь:группа`:** до двоеточия указывается новый хозяин файла (`admin`), после двоеточия — новая группа-владелец (`developers`). Если указать только `:developers`, сменится только группа.

* **`chmod 770 /home/admin/logs`** / **`chmod +x script.sh`** (`change mode` — сменить режим доступа)
  * Управляет правами на чтение (`r` = 4), запись (`w` = 2) и выполнение/вход в папку (`x` = 1).
  * **Цифровой формат `770`:** три цифры отвечают за **Владельца (7)**, **Группу (7)** и **Остальных (0)**.
    * `7` (`4+2+1` = `rwx`) — полный доступ (читать, писать, заходить в каталог).
    * `5` (`4+0+1` = `r-x`) — можно только читать и заходить в папку, но нельзя создавать/удалять файлы.
    * `0` (`0+0+0` = `---`) — полный запрет на любые действия.
  * **Символьный формат `+x`:** добавляет право на выполнение (`execute`) для всех, чтобы текстовый файл можно было запускать как программу/скрипт (`./create_users.sh`).

• `who` — показывает, кто прямо сейчас залогинен в системе, с какого терминала и во сколько зашел.

• `w` — расширенная версия who: показывает не только кто в системе, но и какую именно команду каждый пользователь сейчас выполняет, плюс нагрузку на систему (uptime/load average).

• `last` — читает журнал /var/log/wtmp и выводит историю всех последних входов и перезагрузок системы.
